# Awesome Pixel-Space Video Generation

> A curated collection of pixel-space video generation and generative restoration papers.
> 像素空间视频生成与生成式视频修复论文精选。

## Scope / 收录范围

Core papers model video directly in RGB/pixel space, including diffusion, flow matching, and autoregressive methods. Pixel patches are included when they do not use a learned compressed latent representation. Hybrid methods must explicitly identify which stages operate in pixel space.

核心收录直接在 RGB / 像素空间建模的视频生成论文，并设视频修复分区。采用像素 patch 且不经过学习式 latent 压缩的方法可以收录；混合空间方法需注明像素阶段。
